5 Sécurité

Trois failles critiques/élevées dans React Server Components et Next.js, correctifs disponibles ⚠️ Critique

Netlify et l'équipe Next.js ont publié le 14 octobre trois avis de sécurité : une RCE critique (GHSA-673q-mjm6-r5xr) touchant les apps Next.js 16.x utilisant les Cache Components avec une fonction use cache retournant des typed arrays ; une RCE critique (GHSA-2464-fhr4-w9xw / CVE-2026-96889) dans le traitement SVG via la librairie sharp sur runtime Node.js/glibc Linux ; et un déni de service de sévérité élevée (GHSA-p3m5-59mp-jv5r) dans les Server Actions de App Router, versions 13.x à 16.x. Correctifs : next ≥ 15.5.28 ou 16.4.1, et paquets React Server Components mis à jour vers 19.0.9/19.1.10/19.2.9/19.3.1 selon la version utilisée. Netlify prévient que les deploy previews/branch deploys publics peuvent rester vulnérables tant qu'ils ne sont pas supprimés.

⚠️ Action prioritaire : React 19 est en ADOPT — c'est notre stack frontend par défaut. Vérifier et mettre à jour en urgence toute application Next.js/React Server Components vers les versions corrigées, et purger/supprimer les deploy previews publics obsolètes.
