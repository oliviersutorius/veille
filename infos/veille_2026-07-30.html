Bun — réécriture de Zig vers Rust

🔔 Radar : Bun est en TRIAL suite au POC CI (-65% build time). Surveiller la stabilité pendant la transition Rust avant d'envisager un passage en Adopt.

5 Sécurité

Supply chain npm — TanStack (CVE-2026-45321) et Nx Console (CVE-2026-48027) ⚠️ Critique

Compromission en chaîne toujours activement analysée en juillet : abus de workflows GitHub Actions/trusted-publisher pour publier 84 versions malveillantes sur 42 packages TanStack (CVSS 9.6) — librairies très utilisées pour state management, routing, tables et forms React. Rebond en cascade : la machine d'un contributeur Nx a résolu un package TanStack piégé via pnpm install, un script prepare a exfiltré un token OAuth GitHub CLI, utilisé ensuite pour publier une extension Nx Console malveillante (CVSS 9.8). Les deux CVE sont au catalogue CISA KEV.

⚠️ Action immédiate : Notre stack React/TypeScript utilise potentiellement des packages TanStack (routing, query, table). Auditer les lockfiles et pin les versions connues saines ; vérifier toute présence de Nx Console dans les environnements de dev.

Langflow de nouveau exploité — CVE-2026-55255 ⚠️ Sécurité IA

Ajouté au catalogue CISA KEV début juillet. Rappel : c'est la même famille de faille (RCE Langflow, CVE-2025-3248) qu'avait exploitée JadePuffer, premier ransomware orchestré par LLM documenté (chiffrement autonome d'artefacts/bases IA).

⚠️ Pertinent : Si des frameworks de workflow LLM type Langflow sont utilisés en interne ou en évaluation, exclure/patcher immédiatement toute instance exposée.

FBI — alerte "TeamPCP" sur les outils dev/CI/CD

Groupe systématiquement ciblant les outils de développement et de sécurité de confiance : environnements de dev, pipelines CI/CD, outillage d'audit sécurité — pour voler tokens cloud, clés SSH, secrets Kubernetes et accès corporate.

🔔 Signal : Renforcer la rotation des secrets CI/CD (SOPS + age déjà en ADOPT) et limiter la portée des tokens GitHub Actions.
