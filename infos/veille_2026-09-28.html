1 Intelligence Artificielle / ML

Anthropic lance Claude Opus 5.5 🔔 Radar

Publié le 22 septembre, ce premier modèle de la famille 5.5 offre une fenêtre de contexte à 1M tokens, des performances proches de Claude Fable 5.1, une vitesse de génération +30 % et un coût -40 % vs Opus 5 (4 $ / 20 $ par million de tokens input/output ; cache reads à 0,20 $/M, soit -60 %). 3 Langages & Runtimes

Next.js — faille critique RCE via next/og ImageResponse ⚠️ Critique

CVE-2026-94545 (CVSS 9.5) : correctif hors-cycle publié le 22 septembre par Vercel. Un échappement SVG incorrect dans l'implémentation Node.js d'ImageResponse (next/og, dépendance Satori) peut mener à une exécution de code arbitraire côté serveur si l'application injecte des données contrôlées par l'attaquant dans l'image générée. Versions affectées : Next.js ≥16.2.0 <16.3.6 et 15.5.x avant 15.5.26 (l'implémentation Edge n'est pas affectée). Une seconde vague de correctifs (9 CVE dont 1 critique) est annoncée pour le 30 septembre.

⚠️ Action : Next.js n'est pas une entrée du radar mais dépend de React 19 (ADOPT). Si des projets internes utilisent Next.js + next/og/ImageResponse, patcher en priorité vers 16.3.6 / 15.5.26 et surveiller la vague de correctifs du 30 septembre.

Cinq versions coordonnées publiées le 22 septembre, dont PHP 8.6.0 RC1 (feature-freeze actif) et 8.5.11 (correctifs stables) ; RC2 a suivi le 23 septembre. Sortie stable de 8.6.0 attendue autour de novembre 2026.

Discussion ouverte plusieurs mois avant le prochain feature-freeze.

🔔 Radar : PHP 8.3+ est en ADOPT. Impact informationnel — à surveiller pour un futur cycle PHP 8.7+.

4 DevOps & Observabilité

GitHub Actions compromises « Mini Shai-Hulud » réactivées puis re-désactivées ⚠️ Critique

Deux Actions tierces largement utilisées (actions-cool/issues-helper — ~15 000 dépôts, actions-cool/maintain-one-comment), compromises en mai 2026 puis désactivées, ont été rendues à nouveau accessibles par leur mainteneur entre le 20 et le 24 septembre. Leurs tags de release pointaient toujours vers le payload malveillant (vol de credentials/tokens CI) : tout workflow les référençant par tag (et non par SHA) réexécutait le code. GitHub les a re-désactivées le 25 septembre.

⚠️ Action immédiate : GitHub Actions est notre CI/CD principal (ADOPT). Auditer les workflows internes pour vérifier qu'aucune action tierce n'est référencée par tag mutable (en particulier actions-cool/*) plutôt que par SHA de commit figé. Voir aussi section Sécurité.

5 Sécurité

Citrix NetScaler ADC/Gateway — deux zero-days RCE non authentifiées activement exploitées ⚠️ Critique

Bulletin Citrix CTX697096 du 27 septembre, ajouté au catalogue CISA KEV le même jour. CVE-2026-88771 et CVE-2026-88772 (CVSS 4.0 : 9.5 chacune) : validation d'entrée incorrecte permettant l'exécution de commandes arbitraires non authentifiée sur toute installation par défaut, et débordement mémoire menant à RCE/DoS si DTLS est activé (activé par défaut sur vServer VPN). Exploitation active confirmée avant correctif.

⚠️ Vérification : Citrix NetScaler n'est pas un composant de notre stack, mais à vérifier immédiatement si un appliance NetScaler est utilisé en périphérie (VPN/reverse proxy) ailleurs dans l'entreprise ; patcher sans délai le cas échéant.

Supply chain : malware « Graphalgo » distribué via providers Terraform et modules Go ⚠️ Critique

Rapport Aikido Security du 22 septembre : deux providers Terraform malveillants (gocommunity-io/dockerd, kreuzwenker/docker — ce dernier usurpant un provider Docker légitime totalisant 56M téléchargements) et deux modules Go (gocommunity.io/orderedbtree, gogets.dev/btreex) livrant un RAT en Go, avec déclencheurs conditionnels pour échapper aux tests automatisés. Attribution possible à un acteur nord-coréen (chevauchement avec la campagne Graphalgo). Première observation de malware via des providers Terraform selon Aikido.

⚠️ Action : Go 1.22+ et Terraform 1.x sont en ADOPT. Auditer les providers Terraform/OpenTofu et modules Go utilisés en CI/CD, vérifier hashes/checksums. 🔔 Renforce la pertinence de SLSA (ASSESS) et Sigstore/Cosign (TRIAL) pour la vérification de provenance des artefacts IaC.

Supply chain npm : paquet malveillant « indexed-btree » (~2M téléchargements/semaine) ⚠️ Critique

Rapporté le 21 septembre (The Hacker News), paquet retiré du registre le 3 septembre. Usurpait sorted-btree et contournait les protections classiques (pas de script pre/postinstall) : le code malveillant ne s'activait qu'à l'exécution (fingerprinting hôte, exfiltration via Slack/Telegram, récupération de payloads chiffrés via la technique EtherHiding depuis un smart contract testnet).

⚠️ Impact : touche directement l'écosystème npm/TypeScript/React de l'équipe. Illustre une limite des scans classiques basés sur les install scripts (Trivy/SBOM ne détectent pas ce comportement runtime) — argument pour renforcer le SAST/DAST comportemental.

9 Finance Personnelle & Investissement (informationnel, hors radar tech)

Spread OAT-Bund au plus haut depuis 2012 ⚠️ Alerte finance

L'écart de taux entre l'OAT française à 10 ans et le Bund allemand a franchi les 100 points de base le 22 septembre (102,0 pb, après un pic à 105,36 pb le 18 sept.), un niveau plus revu depuis 2012, reflétant les inquiétudes des marchés sur les finances publiques françaises.

⚠️ Conséquence indirecte pour l'épargne : rendement obligataire plus élevé pour les nouvelles OAT, ce qui peut à terme profiter aux fonds euros d'assurance-vie disposant de liquidités à réinvestir.

CAC 40 : fin d'une séquence de baisse inédite 💰 Info finance

Le CAC 40 a mis fin le 25 septembre à une série de six semaines consécutives de repli (-7,46 % sur la période, séquence jugée rare historiquement), en ne cédant que 0,04 % lors de la séance du vendredi. Contexte toujours marqué par l'incertitude politique française et la tension obligataire.

Livret A, LDDS, LEP : léger sursaut de la collecte en août 💰 Info finance

Chiffres publiés le 23 septembre (portant sur août 2026) : collecte cumulée Livret A + LDDS de 0,54 Md€ (+460 M€ Livret A — 2e collecte positive de l'année ; +80 M€ LDDS, retour au positif après 4 mois de décollecte ; +60 M€ LEP, quasi stable). Encours fin août : 444,2 Md€ (Livret A), 608,9 Md€ (Livret A+LDDS), 83,4 Md€ (LEP). La revalorisation du taux au 1er août (1,7 %) n'a pas changé la perception de compétitivité du produit chez les épargnants.

Livret A : projection d'un taux théorique à 2,00 % ⚠️ Alerte finance

Selon le calcul de la formule officielle appliqué au 25 septembre, le taux théorique recommandé par la Banque de France pour la prochaine échéance serait de 2,00 % (contre 1,7 % actuellement). Projection indicative, pas une annonce officielle — à confirmer lors de la prochaine révision réglementaire.
