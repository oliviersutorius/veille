5 Sécurité

ChainDrop / keyv-shai-hulud — ver auto-propagateur npm ⚠️ Critique

Le 4 août 2026, un ver auto-réplicant a commencé à publier des versions malveillantes des packages keyv et cacheable ainsi que leurs dépendances communes. Le compte mainteneur (Jaredwray) a été compromis : le ver pousse du code malveillant directement sur la branche main puis publie immédiatement une release, obtenant une provenance npm valide signée par GitHub Actions. Le hook preinstall (setup.mjs) télécharge un runtime Bun autonome, exécute un second stage obfusqué, moissonne les identifiants cloud/CI, puis republie en cascade d'autres packages accessibles via le token npm volé. Bilan : 444 packages / 1 381 versions compromis (2 236 versions au total dans l'écosystème touché), pour plus de 2 milliards d'installations mensuelles cumulées — keyv seul (600M+/mois), flat-cache (~580M), cacheable-request (137M+), cacheable (30M+), cache-manager (16M+).

⚠️ Action immédiate : Auditer les lockfiles Node.js/TypeScript pour keyv, cacheable, cacheable-request, cache-manager, flat-cache (dépendances transitives fréquentes des libs de cache/HTTP). Pin sur des versions saines connues, purger les caches CI, faire tourner les credentials cloud/CI si exposition confirmée.

Compromission Axios via compte npm volé ⚠️ Sécurité

La Cyber Security Agency de Singapour a émis une alerte sur une attaque supply chain visant Axios via un compte npm compromis — package HTTP très largement utilisé, y compris potentiellement dans nos stacks TypeScript/Node.js.

⚠️ Action : Vérifier la version d'Axios utilisée et comparer aux versions listées comme compromises dans l'avisory.
