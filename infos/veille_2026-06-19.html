2 Cloud & Infrastructure

AWS EKS — Kubernetes 1.36 disponible (2 juin 2026) ⚠️ Action

EKS supporte désormais Kubernetes 1.36. Changement breaking majeur : le type de volume gitRepo est définitivement désactivé — les pods qui l'utilisent seront refusés par le kubelet (l'API Kubernetes accepte toujours les manifests, mais le kubelet retournera une erreur à l'exécution).

⚠️ Action immédiate : Scanner tous les manifests Kubernetes pour gitRepo volumes avant toute montée de version vers 1.36.

Agentic workloads sur EKS

The New Stack prédit que 2026 sera l'année des workloads agentiques en production sur EKS. Converge avec notre utilisation de Claude API et LangGraph sur nos clusters.
