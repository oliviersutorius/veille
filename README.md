# Programme de Veille Technologique

> Processus structuré et collaboratif de veille technologique pour une équipe de développement.

## Principes directeurs

- **2h max/semaine/développeur** : la veille s'intègre dans le flux de travail, elle ne le remplace pas
- **Factuel et reproductible** : chaque évaluation suit la même grille, sans biais de mode
- **Collectif** : les décisions d'adoption sont prises en équipe, pas individuellement
- **Trimestriel** : le radar est mis à jour tous les trimestres (mars, juin, septembre, décembre)

## Démarrage rapide

1. Chaque développeur choisit **1 domaine de veille** à couvrir en priorité
2. Il consacre **1h/semaine** à la lecture de ses sources
3. Il remplit une **fiche d'évaluation** dès qu'une technologie mérite attention
4. Il présente lors du **tech talk hebdomadaire** (15 min max)
5. L'équipe vote pour le placement dans le **radar trimestriel**
